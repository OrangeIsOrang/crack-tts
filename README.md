# 크랙 TTS

크랙(crack.wrtn.ai) 답변을 Gemini 3.8 TTS로 읽어 주는 Tampermonkey 스크립트입니다.
나레이션과 등장인물을 서로 다른 목소리로 읽습니다.

## 설치

1. 크롬에 [Tampermonkey](https://www.tampermonkey.net/)를 설치하고, 확장 프로그램 세부정보에서 **사용자 스크립트 허용**을 켭니다.
2. **[여기를 눌러 크랙 TTS 설치](https://raw.githubusercontent.com/OrangeIsOrang/crack-tts/main/crack-tts.user.js)**
3. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 받습니다.
4. 크랙 답변 아래 설정 버튼 → **설정** 탭에서 키를 넣고 **확인**을 누릅니다.

새 버전이 올라오면 Tampermonkey가 자동으로 업데이트합니다.

## 기능

- 답변 아래 **읽기** 버튼으로 답변을 읽습니다.
- 등장인물을 자동으로 찾아 성별에 맞는 목소리를 나누고, 작품별로 기억합니다.
- 인물마다 목소리와 말투를 바꿀 수 있습니다.
- **내 목소리**: 구글 목소리 하나에 말투 지시를 더해 나만의 목소리를 만듭니다.
- 상태창처럼 읽지 말아야 할 줄을 거릅니다. 작품별로 남는 줄은 정규식으로 지정합니다.

## 알아둘 점

- 읽는 답변의 본문은 음성 합성과 화자 구분을 위해 구글로 전송됩니다. 다른 곳으로는 보내지 않고, 구글 서버 보관은 끈 채로 요청합니다.
- Gemini API 무료 등급은 입력이 구글 제품 개선에 쓰일 수 있습니다. 결제를 연결하면 유료 등급이 됩니다.
- 요금은 구글 Gemini API 가격을 따릅니다. 만든 음성은 메모리에만 있어서, 새로고침 뒤 다시 들으면 다시 과금됩니다.
- 비공식 스크립트입니다. 크랙 화면이 바뀌면 동작하지 않을 수 있습니다.
